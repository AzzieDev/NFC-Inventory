💡 Android Scanner Diagnostics Guide

  • Browser Requirement: Must be opened in Chrome for Android (iOS Safari does not yet expose Web NFC hardware access to standard JavaScript).
  • Secure Context (HTTPS/Localhost): Browser hardware security mandates this page be served via HTTPS or directly over localhost / 127.0.0.1.
  • Testing via Laragon / Local IP: When opening via local LAN IP (e.g., http://192.168.1.50) on Android Chrome, navigate to chrome://flags/#unsafely-treat-insecure-origin-as-secure, add your server URL, and enable it so Chrome unlocks physical NFC scanning!
